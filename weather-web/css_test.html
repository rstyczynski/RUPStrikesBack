10. Kod CSS - Zmienne

/* Oracle Redwood Color System */
:root {
    --color-bark: #312D2A;      /* Tekst, ramki, łączniki */
    --color-air: #FCFBFA;       /* Główne tło */
    --color-neutral-1: #F5F4F2; /* Jasne wypełnienia */
    --color-neutral-2: #DFDCD8; /* Obszary tła */
    --color-neutral-3: #9E9892; /* Obramowania */
    --color-rose: #A36472;      /* Akcent specjalny */
    --color-sienna: #A85532;    /* Grupy fizyczne */
    --color-ivy: #6B8E23;       /* Elementy logiczne */
    --color-ocean: #0572CE;     /* Główne akcje */
}

Przykład użycia:

.card {
    background: var(--color-air);
    color: var(--color-bark);
    border: 1px solid var(--color-neutral-2);
}

.button-primary {
    background: var(--color-ocean);
    color: var(--color-air);
}

.button-primary:hover {
    background: var(--color-sienna);
}

11. Zasady Do & Don't

✓ TAK

  • Air/Neutral dla tła
  • Bark dla treści
  • Jeden akcent (Ocean/Sienna)
  • ≤6 barw kategorycznych
  • Łączniki 1pt Bark
  • Wysoki kontrast (WCAG)
  • Spójność semantyczna
  • Minimalizm

✗ NIE

  • Wielokolorowe ikony
  • Efekty 3D/cienie
  • Zbyt wiele nasyconych barw
  • >12 kolorów kategorycznych
  • Brak spójności semantycznej
  • Niski kontrast
  • Tylko czerwony-zielony
  • Nadmierna złożoność
