## Design Overview

Single-page web application (vanilla HTML/CSS/JS) consuming Sprint 3 REST API. Mobile-first responsive design with weather icons and 3-day forecast display.

## Key Design Decisions

1. **Vanilla JS over frameworks** - Simplicity for MVP, no build tools
2. **Hardcoded localhost:8080** - Dev environment, easy to parameterize later
3. **Unicode weather symbols** - Zero dependencies, accessible
4. **Mobile-first CSS** - Responsive grid layout (1/2/3 columns)
5. **Browser geolocation API** - "Use Current Location" feature
